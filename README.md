# Zarabiaj Online 2027

Statyczna strona HTML/CSS/JavaScript dla początkujących poszukujących sposobów zarabiania online. Działa na GitHub Pages bez budowania projektu i bez backendu.

## Publikowanie w GitHub Pages

1. Utwórz publiczne repozytorium w GitHub, np. `zarabiaj-online-2027`.
2. Prześlij pliki `index.html`, `.nojekyll` i `README.md` do głównego katalogu repozytorium (Add file → Upload files → Commit changes).
3. Wejdź do **Settings → Pages**, wybierz **Deploy from a branch**, **main** i **/(root)**, następnie **Save**.
4. Po wdrożeniu strona będzie dostępna pod `https://TWOJ_LOGIN.github.io/zarabiaj-online-2027/` (zamień `TWOJ_LOGIN` na swój login).

## Funkcje

- Katalog 17 metod, filtrowanie i wyszukiwarka.
- Linki do oficjalnych stron platform zewnętrznych (otwierane w nowej karcie).
- Quiz, hipotetyczny kalkulator przychodu, planer i ulubione zapisywane w localStorage.
- Responsywny interfejs i grafika 3D w CSS (bez wymaganych bibliotek).

**Uwaga:** To nie jest wyszukiwarka ofert na żywo. Metody i linki prowadzą do serwisów zewnętrznych; rejestracja, dostępność zadań, warunki wieku i wypłaty zależą od tych serwisów. Żaden przychód nie jest gwarantowany. Strona nie posiada logowania ani serwera.
